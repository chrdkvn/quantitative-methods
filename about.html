QUANTITATIVE METHODS PROJECT

Applying mathematics to practical decisions.

Quantitative Methods Decision Lab is a learning-focused web application. Its current working module helps students formulate and solve two-variable linear programming problems using the Simplex Method.

PROJECT PURPOSE

Learn by modeling decisions

This project was created for the study of Quantitative Methods, where mathematical models support structured and evidence-based decisions. The current implementation focuses on linear programming, especially students learning the Simplex Method for the first time. The application provides a workspace for solving optimization problems, examining each tableau iteration, and connecting mathematical procedures with clear visual explanations.

Instead of focusing only on final answers, the project emphasizes understanding the logic behind each step. It helps learners see how constraints are transformed, how pivot operations work, and how the feasible solution develops across iterations.

Project objectives

  • Provide a straightforward interface for MAX and MIN problems.
  • Show the sequence of tableau operations in a clear and step-by-step format.
  • Support learning through examples, guided practice, and short quizzes.
  • Encourage verification of mathematical models, constraints, and final results.
  • Help students translate simple production, resource-allocation, and blending scenarios into linear programming models.
  • Make the subject easier to understand by combining calculation tools with educational explanations.
